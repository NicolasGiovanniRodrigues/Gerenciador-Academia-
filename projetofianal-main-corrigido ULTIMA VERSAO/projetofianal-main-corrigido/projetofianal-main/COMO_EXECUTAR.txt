AUTOMATIC FIT - PROJETO DE CURSO

1. O banco esta configurado neste caminho:
   C:\Users\Aluno\Downloads\projetofianal-main\BANCO.FDB

2. Abra main.py. No inicio do arquivo, procure a funcao conectar().
   O usuario fica na linha user='SYSDBA'.
   A senha fica na linha password='sysdba'.
   Ajuste a senha para a que funciona na sua instalacao do Firebird.
   Essa senha e do banco, nao da conta de aluno ou professor no site.
   Se mover o banco para outra pasta, ajuste a linha database.

3. O Firebird precisa estar instalado e em execucao no seu computador.
   Se as dependencias Python ainda nao estiverem instaladas, execute:
   python -m pip install Flask==3.1.2 fdb==2.0.4 Flask-Bcrypt==1.0.1

4. Execute main.py pelo seu editor ou pelo terminal:
   .\.venv\Scripts\python.exe main.py
   Ou, se usa o Python diretamente:
   python main.py

5. Abra no navegador:
   http://127.0.0.1:5000

Nao ha variaveis de ambiente nem pergunta de senha no terminal.
A conexao esta escrita diretamente na funcao conectar().

Os dados pessoais continuam obrigatorios. O CPF tem 11 numeros,
o telefone com DDD tem 10 ou 11 numeros e o cadastro exige 18 anos completos.

Ao atualizar o codigo, preserve seu BANCO.FDB para nao perder cadastros recentes.
